计算口径说明

同一笔卖出，用不同成本结转方法算出的盈亏可能差很多。本产品两种都支持，逐笔可选，但同一时刻只保留一套结果。

加权平均法 当前默认

卖出结转成本 = 卖出份额 × 当前加权成本。与多数券商 App 展示口径一致，适合长线持有。

指定批次法 做T 用

卖出时指定消耗哪一批买入，按该批买入价计算成本，能看出哪一手真正赚钱。

09计算口径说明

用同一笔卖出的两个结果做对照（+804.40 与 +969.40），比讲公式有效得多。切换按钮写明"会重算全部历史"，把不可逆的代价说在动作之前，而不是点了之后弹警告。

核心路径与状态

设计稿背后的交互决策
首页 · 点「记一笔」 → 选买入 / 卖出 → 价格 · 数量 · 费用 → 批次归属（仅卖出） → 保存回执

REQUIRED STATES

01

批次分配不足：底部按钮置灰并显示「还差 100 股」，只给「先进先出补齐 / 改自动分配」两个出口，不让用户自己算。

02

单批次超卖：步进器上限锁死为该批次剩余量，无法输入超量，从源头消除校验弹窗。

03

成本待补：升级迁移来的老批次缺买入价时，批次卡挂黄色「成本待补」角标，暂以加权成本代替，可点进去补录。

 

04

编辑 / 删除卖出：批次剩余量按交易记录重放重算，不做增量回退，删一笔即自动恢复，不会留脏数据。

05

首次空状态：无持仓时资产卡显示 0.00，列表位替换为「记第一笔」引导，不显示空卡片。

06

未登录：顶部一条 28pt 细提示「本地记录中，登录后自动合并」，不阻断录入。
